# Enterprise Network Architecture & Services

**Conception et mise en place d'une architecture réseau d'entreprise avec Cisco Packet Tracer**

## Présentation du projet

Ce projet consiste à concevoir, simuler et configurer une architecture réseau destinée à une entreprise. Il vise à mettre en place un réseau organisé, fonctionnel et sécurisé, permettant aux différents départements de communiquer et d'accéder aux ressources partagées.

La simulation a été réalisée avec **Cisco Packet Tracer**, afin de représenter les équipements réseau, de configurer les services et de vérifier le fonctionnement de l'infrastructure.

## Objectifs

- Concevoir une architecture réseau adaptée aux besoins d'une entreprise.
- Organiser le réseau à l'aide des VLAN.
- Configurer le routage inter-VLAN.
- Mettre en place les services réseau essentiels.
- Assurer la communication entre les différents équipements.
- Appliquer des mesures de sécurité et contrôler les accès.

## Technologies et outils utilisés

- Cisco Packet Tracer
- Équipements Cisco (routeur et switches)
- VLAN et routage inter-VLAN
- DHCP et DNS
- Serveurs Web, FTP et messagerie
- SSH
- ACL et Port Security

## Fonctionnalités mises en place

| Service | Description |
|---|---|
| DHCP | Attribution automatique des adresses IP |
| DNS | Résolution des noms de domaine |
| Web | Hébergement d'un site public et d'un site intranet |
| FTP | Transfert de fichiers |
| Messagerie | Envoi et réception de courriels |
| SSH | Administration à distance des équipements |
| VLAN | Segmentation logique du réseau |
| ACL | Contrôle des communications réseau |
| Port Security | Protection des ports des switches |

## Architecture réseau

L'infrastructure repose sur une topologie en étoile organisée autour d'un routeur et de switches. Le réseau est segmenté en plusieurs VLAN afin de séparer les différents départements et les serveurs.

Une zone DMZ est également prévue pour héberger le serveur Web public, tandis que les ressources internes sont protégées par des règles de contrôle d'accès.
